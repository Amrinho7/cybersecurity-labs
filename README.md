# Sorting & Searching Project (C++)

This project analyzes carbon emission data using different algorithms and data structures.

## Features
- Sorting algorithms (Array & Linked List)
- Searching techniques
- Performance analysis (time & memory usage)
- CSV dataset processing

## Files
- C++ source code (.cpp, .h)
- CSV datasets (city carbon data)

## How to Run

Compile:
g++ *.cpp -o program

Run:
./program

## Tools Used
- C++
- VS Code
- GitHub
